# Voice & Style Bible

Paste your own chapter in the first chapter, then ask an AI to complete this analysis.

| Category | What the AI should learn |
| --- | --- |
| Narrative voice | Person, intimacy, distance |
| Sentence construction | Short, long, compound, varied |
| Vocabulary | Sophistication, colloquialisms, unusual words |
| Description | Visual, atmospheric, sensory, restrained |
| Humour | Dry, sarcastic, dark, observational |
| Dialogue | Naturalistic, theatrical, understated |
| Pacing | Slow passages versus rapid sequences |
| Characterisation | Behaviour or exposition |
| Metaphors | Frequency, originality, complexity |
| Reader relationship | What is explained and what is left unsaid |

## Things to avoid
- Unnecessary exposition.
- Explaining emotions already clear from behaviour.
- Repetitive descriptions.
- Generic AI-sounding dialogue.
- Excessive adjectives and contrived metaphors.
- An artificial cliffhanger at the end of every chapter.
