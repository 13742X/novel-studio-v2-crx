# Continuity Ledger

Record what has changed after each chapter, not just what happened.

| Category | Information |
| --- | --- |
| Chronology | Events and dates |
| Characters | Current location and physical state |
| Emotional state | What each character is feeling |
| Knowledge | What each character now knows |
| Relationships | Changes in relationships |
| Objects | Significant objects and where they are |
| Plotlines | Open and resolved threads |
| Foreshadowing | Details planted for later |
